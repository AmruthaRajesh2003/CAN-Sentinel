# CAN-Sentinel: Automotive ECU Intrusion Detection System

## Project Introduction

CAN-Sentinel is a beginner cybersecurity project that aims to detect suspicious activity in simulated automotive CAN bus messages.

## Objectives

- Understand automotive CAN communication.
- Analyze sample CAN message data.
- Identify unusual message patterns.
- Generate alerts for suspicious activity.

## Tools

- Python
- CSV
- Git and GitHub
